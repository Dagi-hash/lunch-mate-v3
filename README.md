# LunchMate

Capacitor (web) app. `www/` is the app, `resources/` holds the Android customisations (applied inline by the workflow)
(icons, reminder sound, splash, permissions), and `.github/workflows/main.yml` builds the APK on GitHub.

## Get the APK
1. Create a GitHub repo and push everything in this folder (the `android/` folder is generated by CI, don't commit it).
2. Open the repo -> **Actions** -> **Build LunchMate APK** (it runs on every push; or press **Run workflow**).
3. When it turns green, open the run and download **LunchMate-debug-apk** from *Artifacts*. Unzip -> `app-debug.apk`.

## Change the light-mode colours
Open `www/styles.css` and edit only the block `:root[data-theme=light]` (every colour is a variable).

## Notes
- Reminder sound file: `resources/android/raw/reminder.wav` (and `www/reminder.wav` for in-app). Replace both with your own .wav.
- If you installed an older LunchMate, uninstall it first or install over it (same package id, data is kept).
